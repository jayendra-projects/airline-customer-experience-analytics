# airline-customer-experience-analytics
Python customer analytics project using 50,000 airline reviews to analyse customer sentiment, benchmark service performance, identify experience drivers and translate insights into business recommendations.

## Project Overview

This project analysed approximately **50,000 airline customer reviews** to identify customer sentiment, service-performance patterns and recurring drivers of passenger experience.

Python was used to prepare and analyse large-scale customer review data, combining quantitative performance analysis with Natural Language Processing (NLP) techniques to convert unstructured customer feedback into business insights.

The project examined differences in customer experience across airlines, identified positive and negative sentiment patterns, and extracted recurring themes from customer reviews to understand the factors influencing customer satisfaction.

The analytical workflow followed:

**Business Problem → Data Preparation → Exploratory Data Analysis → Airline Performance Benchmarking → Sentiment Analysis → Topic Modelling → Customer Experience Insights → Business Recommendations**

---

## Business Objective

The analysis was designed to answer business questions including:

- How does customer satisfaction differ across airlines?
- Which airlines demonstrate comparatively higher or lower customer sentiment?
- What recurring issues appear within negative customer reviews?
- Which aspects of the passenger experience contribute to positive feedback?
- What themes can be extracted from large volumes of unstructured customer feedback?
- How can customer-review data be translated into actionable service-improvement opportunities?

---

## Python Analytics Approach

Python was used throughout the analytical workflow to transform raw customer-review data into structured business insights.

Key activities included:

- importing and inspecting customer-review datasets;
- cleaning and preparing review data;
- handling missing and inconsistent information;
- performing exploratory data analysis;
- aggregating airline-level performance measures;
- analysing customer-rating distributions;
- visualising trends and comparative performance;
- applying sentiment analysis to customer-review text;
- extracting recurring themes using NLP and topic-modelling techniques; and
- translating analytical findings into business recommendations.
